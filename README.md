# على قدر العقول

مقال عربي تفاعلي عن الذكاء الاصطناعي بوصفه مضاعفاً إدراكياً، مع عرض مناسب للطباعة مع خيار حفظ نسخة PDF عبر نافذة الطباعة.

**الموقع:** https://kakramah.github.io/cognitive-multiplier-ai/

## البنية

- `index.html`: المقال وبنية الصفحة وبيانات المشاركة.
- `styles.css`: التصميم، بما فيه تنسيق الطباعة.
- `app.js`: تفاعل الصفحة ونموذج التواصل وفتح نافذة الطباعة.
- `brand/` و`images/` و`fonts/`: الأصول.

## المعاينة

من جذر المستودع:

```sh
python3 -m http.server 8000
```

افتح `http://localhost:8000/`، وراجع المقال على الهاتف والحاسوب ومعاينة الطباعة. عند تعديل التفاعلات افحص نافذة الطباعة والنموذج، ولا ترسل بيانات تجريبية حقيقية عبر النموذج. لا توجد خطوة بناء في جذر المستودع.
